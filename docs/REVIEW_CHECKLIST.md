# Checklist review

- [ ] Đúng và đủ tiêu chí chấp nhận trong spec? Có làm thừa không?
- [ ] Mình hiểu mọi file bị thay đổi chưa? Dòng nào chưa hiểu?
- [ ] Test kiểm tra hành vi hay chỉ chạy cho có? Có ca biên và ca lỗi không?
- [ ] Có lỗi bị nuốt im lặng không: except quá rộng, giá trị mặc định che lỗi?
- [ ] Có thư viện mới không? Vì sao cần?
- [ ] Có secret, dữ liệu cá nhân hay quyền mới nào bị đụng tới không?
- [ ] Tốn thêm bao nhiêu lần gọi LLM, bao nhiêu token?
- [ ] Có cách đơn giản hơn không?
